Faceless Channel Automation

A personal automation tool that runs a single YouTube channel I own.

Faceless Channel Automation is a private, personal-use application built and operated by me, Andre Al Thubian, to automate the production and publishing of videos on my own YouTube channel. It is not a public product, it is not offered to other users, and nobody other than me signs in to it.

What it does

  • Reads a list of video topics and scripts from a Google Sheet that I own and maintain.
  • Generates video scripts and renders video files using third-party production tools (AI script generation, text-to-speech, stock footage, and video rendering services).
  • Uploads the finished videos directly to my own YouTube channel using the YouTube Data API.
  • Writes status updates (such as render status and the resulting video link) back to the same Google Sheet so I can track what has been published.

Who uses it

Only me. This application authenticates with my own Google account to act on my own Google Sheet and my own YouTube channel. It does not authenticate on behalf of, or access data belonging to, any other person.
