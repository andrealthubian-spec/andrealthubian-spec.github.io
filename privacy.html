Privacy Policy

Effective October 5, 2026

This policy explains how "The Actual Takeaway" publishing tool (the "App") handles information, including data received from Google APIs. The App is a private automation tool operated by the owner of The Actual Takeaway YouTube channel for managing that channel. It is not offered to the public.

Who uses the App

The only person who signs in to the App with Google is the channel owner. The App does not collect data from viewers, visitors to this website, or any other Google users.

Google user data the App accesses

With the owner's permission, the App accesses only the following data in the owner's own Google account:

  • YouTube Data API and YouTube Analytics API: the ability to upload videos and set thumbnails on the owner's channel, and read-only access to the channel's own video metadata, statistics and analytics (such as views and audience retention).
  • Google Sheets API: read and write access to the owner's spreadsheets used for planning and logging uploads.
  • Google Drive API: the ability to create, store and share files (such as voiceover audio) in the owner's Drive.

How the data is used

This data is used only to provide the App's features to the owner: publishing the owner's videos, recording what was published, and producing performance reports for the owner. The data is not used for advertising, is not sold, and is not used to build profiles of anyone.

How the data is stored

OAuth access tokens are stored encrypted in the owner's self-hosted automation server. Channel statistics and logs are stored in the owner's own Google Sheets and Drive. No Google user data is stored in any other database.

Sharing

Google user data is not shared with, transferred to, or sold to any third party. The App uses outside services to produce video content (text and image generation, text-to-speech, stock footage and video rendering), but those services receive only content the owner creates, not data obtained from the owner's Google account.

Google API Services User Data Policy

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The App uses YouTube API Services. By using the App you also agree to the YouTube Terms of Service, and the Google Privacy Policy applies to data handled by YouTube and Google.

Retention and deletion

Data is kept only as long as the owner needs it to run the channel. The owner can revoke the App's access at any time from the Google security settings page, which stops all further access. Stored tokens are then deleted from the automation server, and logs can be deleted by deleting the related spreadsheets. To ask about or request deletion of any data, email the contact address below.

Cookies

This website does not use cookies or tracking.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
